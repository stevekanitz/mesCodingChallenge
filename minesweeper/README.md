# Minesweeper
Windows no longer includes a desktop version of Minesweeper out of the box. Let's add a desktop version back!

# Requirements
- Implement the behavior for the game starting in the form [Main.cs](Main.cs). The 2 event handlers there should provide the necessary starting points to drive the rest. Make the game operate as close to the original as possible.
- Minefield area is 9 x 9.

# Tools Needed
Use a text editor like [VS Code](https://code.visualstudio.com/).

Verify dotnet is installed, or install from [here](https://dotnet.microsoft.com/en-us/download):
```bash
dotnet --info
```
# Getting Started
To build the app from the console/terminal:
```bash
dotnet build
```

To run the app:
```bash
dotnet run
```
